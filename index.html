Security Centre

Encryption, sessions and activity.

Data encryption

AES-GCM 256-bit vault encryption
All financial records are encrypted with your session key before touching storage. Decryption happens only in memory while you're signed in.
Active
Password hashing
Credentials stored as PBKDF2-SHA256 hashes with per-vault random salt. We never see — or could reconstruct — your password.
Active
Zero-knowledge architecture
No server, no account database, no analytics, no third-party scripts. There is literally nothing to breach.
