# Budgetelle 🔐

**Your money, guarded. Tracked. Grown.**

A private-by-design personal finance vault: budgeting, net worth, goals, assets, insurance, loans — plus a built-in **Advisor** that answers affordability questions ("Can I afford to travel to Paris?", "Can I buy a new phone?") from *your* real numbers.

## Privacy & Security
- **Zero-knowledge / zero-server**: all data lives in your browser's local storage
- **AES-GCM 256-bit encryption** of every financial record
- **PBKDF2-SHA256 (150k iterations)** salted password hashing
- No accounts database, no analytics, no trackers, no third-party scripts
- GDPR-aligned: full export (portability) and one-click vault erasure

## Features
- Dashboard with KPIs, cash-flow chart, spending donut, renewal radar
- Separate **Income** and **Expenses** tabs
- Budgets, Recurring subscriptions, Net Worth snapshots + trend
- Goals with projections, Assets, Insurance & document expiry alerts
- Credit card reward rules + best-card recommender
- **Advisor** tab — local affordability engine, no AI server involved
- Dark / light theme toggle
- USD ($ default) + multi-currency support with custom rates

## Stack
Vanilla HTML/CSS/JS. No build step. No backend. Deploy anywhere static.

## Run locally
Open `index.html`, or `npx serve .`
